FREE GITHUB PAGES DEPLOYMENT
1. Sign in/create an account at https://github.com/
2. Create a public repository named aadyashri-tissue-papers-website.
3. Upload index.html, styles.css, script.js, README-DEPLOYMENT.txt and the full assets folder to the repository root.
4. Open Settings → Pages.
5. Select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for the public URL displayed in Settings → Pages.
7. The URL will resemble https://YOUR-USERNAME.github.io/aadyashri-tissue-papers-website/ (example only).
8. Before sharing, confirm phone numbers, product grades, images and order specifications.

PRODUCT CONTENT NOTES
The website describes GSM ranges as indicative only. Actual grades, ply, finish, printing, dimensions, packaging, availability and pricing should be confirmed with the raw-material supplier and in the quotation for each order. The 70 GSM grade is noted as not typical for tissue napkins.

GitHub Pages hosts static websites for free. A custom domain may cost extra.
